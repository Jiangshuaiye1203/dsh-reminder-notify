# 桌面提醒 dsh-reminder-notify

给 DeepSeek Harness 加一个 `notify_user` 工具：模型在任务收尾（`kind=done`）或征求同意之前（`kind=decide`）调用它，屏幕右下角弹出提醒卡片并播放对应语音，不抢焦点、按秒自动关闭。

卡片宿主是包内的 `host/ReminderHost.ps1`——用系统自带的 PowerShell 5.1 + WinForms 在运行期绘制，仓库里没有任何 exe，下载安装不会被 SmartScreen / 杀软拦。

## 设置

在「插件」页打开「桌面提醒」，描述下方就是设置面板，分七组：

- **基本**：停留秒数、弹窗位置、是否播放提示音
- **提示音**：提示音目录（可点「浏览…」选目录）、三档提示音文件名（wav / mp3），选了目录后下拉框会列出目录里的音频
- **外观**：背景图、标题图标、强调色、标题/正文模板（`{title}` `{message}` `{kind}` `{time}`），以及每档位单独覆盖的背景 / 图标 / 模板
- **排队与免打扰**：语音朗读、卡片按钮、「稍后提醒」分钟数、排队开关与上限、合并窗口、免打扰时段与处理方式、全屏时用紧凑卡片
- **历史与统计**：是否记录、保留条数，面板里直接显示总条数 / 今日条数与最近 8 条记录，可「刷新」和「清空」
- **DeepSeek 余额**：开关、阈值（默认 20,10,5 %）、检查间隔、是否语音播报；面板里能「立即查询」，也能把当前余额设为基线
- **宿主**：脚本模式或 exe 模式、脚本路径、PowerShell 路径

改完点「保存」，立刻生效，不用重启。

## 提醒的行为（0.11 起）

- **排队**：一次只显示一张卡，后来的进队列（`queueEnabled` / `queueMax`），不再一叠好几张。
- **合并**：同档位在 `mergeWindowMs`（默认 3 秒）内再次触发，会并进排队中的那一条，正文按行拼起来、最多 600 字。
- **按钮**：「知道了」立即关；「稍后提醒」把这条按 `snoozeMinutes`（默认 10）延后重弹。不点按钮就是到时自动关。
- **免打扰**：`quietEnabled` 打开后，`quietStart`–`quietEnd`（支持跨零点）内不弹「完成」和普通提醒：
  `quietMode: hold` 留到时段结束后补弹，`skip` 直接丢弃；**「需要你来决定」任何时段都照弹**。
- **全屏降级**：检测到前台是全屏应用时改画窄卡片，少挡内容（`compactOnFullscreen`）。
- **语音朗读**：`speakEnabled` 用 `System.Speech` 念出标题与正文，需要系统装了中文语音包。
- **历史**：每条提醒结束都会记一条（自动关闭 / 点了卡片 / 知道了 / 稍后提醒 / 免打扰跳过），
  存在 `~/.dsh/dsh-reminder-notify/history.json`，超过 `historyLimit` 丢最旧的。
  面板里能看到总计与今日条数、最近 8 条，也可以清空。

## DeepSeek 余额提醒

余额数据来自本机已登录的 DSH 账号（宿主 `deepseekAccount` 服务），不需要 API key。

「剩 20%」得有个分母，插件用的是**基线**：最近一次充值后的余额。第一次检查时把当前余额记为基线；之后余额比基线还高（说明刚充过值）就自动把基线抬上去并重新待命。余额跌到 基线 × 阈值% 以下就弹卡 +（可选）语音播报，同一档只报一次。

基线口径（0.10.1 起）：

- **只认「充值余额」**，赠送金单独显示、不计入百分比（否则赠送金到期清零会误报）；
- 基线绑定**账号身份与设定时间**，换 DeepSeek 账号会自动重来，面板上能看到「基线 ¥x（自动/手动 · 时间）」；
- 刚充值/刚抬升基线的 **30 分钟内不播报**，并且要**连续两次查到低于阈值**才响，避免充值入账被冲正之类的抖动误报；
- 查不到余额（未登录、接口失败）时保留上次结果，只显示过期提示，不会当成 0 元去喊。

## 已知限制

- 仅 Windows（`os: ["win32"]`）：卡片宿主是 WinForms。
- 每次弹卡片要起一个 PowerShell 进程，`Add-Type` 编译约 0.6 s 才出现。
- 卡片随 DSH 宿主进程存活；DSH 关掉时正在显示的卡片也会一起消失。
