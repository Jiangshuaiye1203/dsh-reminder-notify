# 桌面提醒 dsh-reminder-notify

给 DeepSeek Harness 加一个 `notify_user` 工具：模型在任务收尾时弹「完成」卡，在要你拍板前弹「需要你来决定」卡，屏幕右下角、带语音、不抢焦点、按秒自动关闭。

卡片由包内的 `host/ReminderHost.ps1` 用系统自带的 PowerShell 5.1 绘制，仓库里没有 exe，安装不会触发 SmartScreen。

## 怎么用

- **只想改外观和停留时间**：改下面「基本」那一组，点「保存」就生效。
- **想马上看效果**：点「试试看」里的三个按钮，各弹一张样卡，20 秒自动关。
- **想推到手机**：在「日报与推送」里打开推送、选格式、填自己的 webhook 地址（企业微信机器人或 Server 酱），点「现在发一条」验证。
- **其余说明**：全部收在下面设置面板的「使用说明（点开才看）」里，一次只展开一条。
