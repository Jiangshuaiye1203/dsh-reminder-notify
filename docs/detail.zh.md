# 桌面提醒 dsh-reminder-notify

给 DeepSeek Harness 加一个 `notify_user` 工具：任务收尾弹「完成」卡，要你拍板前弹「需要你来决定」卡；右下角、带语音、不抢焦点、按秒自动关闭。卡片由包内 PowerShell 脚本绘制，没有 exe。

**所有开关都在下面这个面板里**：「基本」第一行就是三张样卡（想看效果直接点），其余分组点标题展开，「使用说明（点开才看）」里逐条细讲；版本更新见 README。
- 0.36：面板里有「自定义规则」（写 JSON，校验通过才保存）与「响应速度」统计（平均 / 中位 / 被忽略占比，按档位分开）。
- 0.37：卡片可以带时间按钮（`pickTimes`），点一下就在那个时间再提醒一次。
