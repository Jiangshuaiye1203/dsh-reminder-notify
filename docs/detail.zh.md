# 桌面提醒 dsh-reminder-notify

给 DeepSeek Harness 加一个 `notify_user` 工具：模型在任务收尾时弹「完成」卡，在要你拍板前弹「需要你来决定」卡，屏幕右下角、带语音、不抢焦点、按秒自动关闭。

卡片由包内的 `host/ReminderHost.ps1` 用系统自带的 PowerShell 5.1 绘制，仓库里没有 exe，安装不会触发 SmartScreen。

## 怎么用

- **只想改外观和停留时间**：改下面「基本」那一组，点「保存」就生效。
- **想马上看效果**：点「试试看」里的三个按钮，各弹一张样卡，20 秒自动关。
- **想推到手机**：在「日报与推送」里打开推送、选格式、填自己的 webhook 地址（企业微信机器人或 Server 酱），点「现在发一条」验证。
- **其余说明**：全部收在下面设置面板的「使用说明（点开才看）」里，一次只展开一条。
- **给别的插件用**：本插件对外提供 `reminder` 服务（`notify` / `digest` / `stats` / `config`），写法见 README。
- 自检里新增「GitHub 连通性」：hosts 里有指向 127.0.0.1 的 github 行（Steam++ 加速表）时标红，另有「测 GitHub」按钮现测一次；推送用 `scripts/github-push.ps1` 可自动处理并还原。
- 0.17 新增：定时提醒（`at` / `inMinutes`）、`decide` 优先、单卡最长停留、卡上「打开链接」按钮与 Enter/S/Esc 快捷键、历史导出 CSV/JSON、Telegram/飞书/钉钉推送格式、服务契约第 2 版。
- 0.18 新增：条件提醒（余额 / 排队 / 宿主失败 / 免打扰 / 条数，各自可关）、原生系统通知（`toastEnabled`）、托盘图标与全局热键（`Ctrl+Alt+R`），面板「工程与可靠性：自检」里可启停托盘与试发通知。
- 0.19 新增：周期提醒（`every: "30m"` + `times`，面板「历史与统计」里能看下次时间并取消）、历史 30 天柱状图（每天一根，悬停看日期与条数）。
- 0.20 新增：卡片上可以直接回话（`replyEnabled`，打完按 Enter 回给模型，回复进历史并按 `pushReply` 推手机）、自定义按钮（`customButtons`，「标签|网址」分号分隔，单条提醒也能带自己的按钮）、专注助手静音（`focusAssistMute`，专注助手/演示模式开着时照弹不响）。
- 0.21 新增：手机页面。面板「高级：历史、余额与宿主」里有局域网地址（`mobileToken` 做口令），手机连同一个 Wi-Fi 打开就能看最近提醒并回一句话，回话进历史、也按 `pushReply` 推到手机；不走公网、不需要备案。

- 0.22 新增：手机页面可「安装到桌面」（PWA：图标 + 全屏 + 离线缓存）；手机回话会自动出现在模型下一步的提示词里（读走即标记已读，`GET/POST /dsh-reminder-notify/mobile/inbox` 可查看与清空未读）。

- 0.22.1 修正：手机页在内网 http 地址上不再假装能「安装到桌面」——http 给「添加到主屏幕」的手动说明（iPhone Safari 分享菜单 / Android Chrome 菜单），service worker 与离线缓存只在 https 或 localhost 下启用。
- 0.23 新增：手机回话可以带 1–3 个图片或语音（存在本机 `~/.dsh/dsh-reminder-notify/uploads/`），历史里显示「附件 N」，提示词里会带文件名。
- 0.24 新增：手机页升级成小 App——概览（统计 + 7 天柱状图）、历史（按档位筛选、每页 20 条翻页）、设置（五个开关 + 导出 CSV/JSON + 只读状态）。
