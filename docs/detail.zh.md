# 桌面提醒 dsh-reminder-notify

给 DeepSeek Harness 加一个 `notify_user` 工具：任务收尾弹「完成」卡，要你拍板前弹「需要你来决定」卡；右下角、带语音、不抢焦点、按秒自动关闭。卡片由包内 PowerShell 脚本绘制，没有 exe。

**所有开关都在下面这个面板里**：改外观改「基本」，想马上看效果点「试试看」，其余细节点开面板里的「使用说明（点开才看）」逐条读；版本更新见 README。
- 0.28：决定卡的 `options` 候选按钮（点了哪个会进历史，也会出现在我下一步的上下文里）。
- 0.31：面板「基本」最上面有「弹出窗口」总开关；日报今天发过就不再补发，当天没提醒也不弹。
- 0.32 新增：面板里有「本插件下载量」（npm 公开统计）与「反馈与留言」（存本机，可一键提交 GitHub issue）。
- 0.33 新增：面板「备份与恢复」（每天自动备份、可导出/导入/恢复）+ `scripts/release.ps1` 一键发版。
- 0.34：决定卡支持「其他…」输入、周期提醒可限定工作日/周末/指定星期、可按档位静音（面板与手机页都能改）。
